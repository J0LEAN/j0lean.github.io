Pépouze est une application d'automatisation : vous créez des macros (« Quand… Faire… Seulement si… ») qui s'exécutent sur votre téléphone. Cette page explique quelles données l'application utilise, pourquoi, et ce que vous contrôlez.

En bref

  • Vos macros et leur historique restent sur votre téléphone. Rien n'est envoyé sans une action de votre part.
  • Pas de mesure d'audience, pas de revente de données.
  • Quatre fonctions facultatives envoient des données hors du téléphone, seulement si vous les utilisez : la sauvegarde dans un fichier (si vous choisissez un emplacement en ligne comme Google Drive), le compte (sauvegarde en ligne), Claude avec votre clé API et les requêtes web que vous ajoutez vous-même à vos macros.

Données enregistrées sur le téléphone

  • Vos macros, y compris les numéros de téléphone, textes et adresses web que vous y écrivez, et l'historique de leurs exécutions.
  • Vos préférences (conseils masqués, sauvegarde automatique…).
  • Si vous connectez Claude : votre clé API, chiffrée avec une clé du Keystore Android qui ne quitte jamais le téléphone, et exclue des sauvegardes.

Ces données sont effacées quand vous désinstallez l'application. Si la sauvegarde de votre téléphone est activée dans les réglages d'Android, Android peut aussi les copier dans la sauvegarde de votre compte Google pour les remettre en place après une réinstallation (jamais la clé API).

Sauvegarde dans un fichier (facultatif)

Si vous touchez « Sauvegarder mes macros », Pépouze écrit vos macros dans le fichier que vous créez avec le sélecteur de fichiers d'Android : sur Google Drive, sur le téléphone, sur une carte mémoire… Si « Auto » est activé, ce fichier est mis à jour à chaque modification. Pépouze n'accède qu'à ce fichier ; c'est l'application de stockage que vous avez choisie qui le conserve, selon ses propres règles. « Restaurer une sauvegarde » lit seulement le fichier que vous choisissez.

Compte et sauvegarde en ligne (facultatif)

Si vous créez un compte, Pépouze utilise Firebase, un service de Google :

  • Firebase Authentication : votre adresse e-mail et votre prénom si vous le donnez, ou votre compte Google si vous choisissez « Continuer avec Google ».
  • Cloud Firestore : une copie de vos macros, la date de la sauvegarde et le modèle du téléphone qui l'a faite.

Ces données ne sont accessibles qu'avec votre compte. Vous pouvez vous déconnecter, ou supprimer votre compte et sa sauvegarde dans Mon compte → Supprimer mon compte. Google traite ces données selon sa politique : https://firebase.google.com/support/privacy

Créer un module avec l'IA

  • Pépouze (par défaut) fonctionne entièrement sur le téléphone : rien n'est envoyé.
  • Claude avec votre clé API (facultatif) : après votre accord, votre demande et le nom de vos macros sont envoyés à Anthropic pour préparer le module. Politique d'Anthropic : https://www.anthropic.com/legal/privacy
  • ChatGPT ou Claude sans clé : Pépouze ouvre l'application ChatGPT ou Claude (ou leur site) avec votre demande et le nom de vos macros prêts à envoyer, et les copie aussi dans le presse-papiers ; c'est vous qui les envoyez. À votre retour, Pépouze lit le presse-papiers pour importer la réponse, ou la clé API que vous venez de copier (qu'elle efface ensuite).
  • Comprendre d'autres langues que le français : pour lire une demande écrite dans une autre langue, Pépouze télécharge une seule fois un modèle de traduction de Google (ML Kit), puis traduit sur le téléphone. Votre demande n'est jamais envoyée.

Autorisations

Au premier lancement, Pépouze ne demande que l'essentiel (notifications et service d'accessibilité) et présente les autres autorisations avec leur explication. Les autres vous sont demandées, avec leur explication, seulement quand une de vos macros en a besoin. Une macro qui en a besoin ne s'active pas tant que vous ne l'avez pas accordée, et vous pouvez retirer une autorisation à tout moment dans les réglages d'Android.

  • Notifications : afficher les notifications de vos macros.
  • Alarmes et rappels : déclencher les macros horaires à la minute près.
  • Batterie sans restriction : éviter qu'Android mette Pépouze en veille ; vous la choisissez vous-même dans la page de l'application des réglages d'Android.
  • Accès « Ne pas déranger » : changer ce mode et passer la sonnerie en silencieux.
  • Modifier les paramètres système : luminosité, mise en veille et rotation de l'écran.
  • Appareils à proximité : savoir quand un appareil Bluetooth se connecte.
  • Appels téléphoniques : composer le numéro choisi dans une macro.
  • Service d'accessibilité : voir la section suivante.
  • Internet : sauvegarde en ligne, Claude, requêtes web de vos macros, en https uniquement.

Pépouze n'envoie jamais de SMS elle-même : l'action « Préparer un SMS » ouvre votre application de messages, et c'est vous qui touchez Envoyer.

Service d'accessibilité

S'il est activé, avec votre accord et après une explication dédiée, il sert uniquement à exécuter vos macros : toucher l'élément qui affiche le texte que vous avez indiqué, utiliser les boutons système, verrouiller l'écran, faire une capture, savoir quelle application s'ouvre et ouvrir une application quand Pépouze n'est pas affichée.

Il lit le nom de l'application qui s'ouvre, pour l'événement « Appli ouverte », et cherche à l'écran le texte que vous avez indiqué, seulement pendant l'action « Toucher un texte à l'écran ». Ces informations ne sont ni envoyées ni partagées. Seule la mention de ce qui a lancé une macro (par exemple « Appli ouverte : Waze ») est notée dans l'historique de vos macros, sur votre téléphone.

Pépouze n'agit jamais d'elle-même : elle suit seulement les règles que vous avez écrites. Vous pouvez couper le service à tout moment dans les réglages d'accessibilité d'Android.

Sécurité

Connexions chiffrées uniquement (HTTPS), clé API chiffrée sur le téléphone, et accès à la sauvegarde en ligne réservé à votre compte par des règles de sécurité.

Enfants

Pépouze ne s'adresse pas aux enfants de moins de 13 ans.
