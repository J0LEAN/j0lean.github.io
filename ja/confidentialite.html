Pépouze は自動化アプリです。あなたが作るマクロ（「いつ… 実行… 条件…」）は、あなたのスマホの中で実行されます。このページでは、アプリがどんなデータを使うのか、その理由、そしてあなたが管理できることを説明します。

概要

  • マクロとその履歴は、あなたのスマホの中にとどまります。あなたが操作しない限り、何も送信されません。
  • アクセス解析はなく、データを販売することもありません。
  • スマホの外にデータを送信する任意の機能は 4 つあり、あなたが使った場合にだけ送信されます：ファイルへのバックアップ（Google ドライブなどオンラインの保存先を選んだ場合）、アカウント（オンラインバックアップ）、ご自身の API キーを使った Claude、そしてご自身でマクロに追加したウェブリクエストです。

スマホに保存されるデータ

  • マクロ（その中に入力した電話番号、テキスト、ウェブアドレスを含む）と、その実行履歴。
  • 設定（非表示にしたヒント、自動バックアップなど）。
  • Claude に接続している場合：API キー。スマホの外に出ることのない Android Keystore の鍵で暗号化され、バックアップの対象外です。

これらのデータは、アプリをアンインストールすると消去されます。Android の設定でスマホのバックアップが有効になっている場合、再インストール後に復元できるよう、Android がこれらのデータを Google アカウントのバックアップにコピーすることもあります（API キーは対象外です）。

ファイルへのバックアップ（任意）

「マクロをバックアップ」をタップすると、Pépouze は Android のファイル選択画面であなたが作成したファイルにマクロを書き込みます。保存先は Google ドライブ、スマホ本体、メモリーカードなどです。「自動」がオンの場合、変更のたびにこのファイルが更新されます。Pépouze がアクセスするのはこのファイルだけです。ファイルは、あなたが選んだストレージアプリが、そのアプリ独自のルールに従って保管します。「バックアップを復元」は、あなたが選んだファイルだけを読み込みます。

アカウントとオンラインバックアップ（任意）

アカウントを作成すると、Pépouze は Google のサービスである Firebase を使用します：

  • Firebase Authentication：メールアドレスと名前（入力した場合）、または「Google で続行」を選んだ場合は Google アカウント。
  • Cloud Firestore：マクロのコピー、バックアップの日付、バックアップしたスマホの機種。

これらのデータには、あなたのアカウントでしかアクセスできません。ログアウトすることも、マイアカウント → アカウントを削除 から、アカウントとそのバックアップを削除することもできます。Google はこれらのデータを、自社のポリシーに従って取り扱います：https://firebase.google.com/support/privacy

AI でモジュールを作る

  • Pépouze（標準）は、すべてスマホの中で動作します。何も送信されません。
  • ご自身の API キーを使った Claude（任意）：あなたの同意のあと、モジュールを準備するために、あなたのリクエストとマクロの名前が Anthropic に送信されます。Anthropic のポリシー：https://www.anthropic.com/legal/privacy
  • キーなしの ChatGPT または Claude：Pépouze は ChatGPT または Claude のアプリ（またはそのウェブサイト）を開き、あなたのリクエストとマクロの名前を送信できる状態で用意し、クリップボードにもコピーします。送信するのはあなたです。アプリに戻ると、Pépouze はクリップボードを読み取り、回答、またはコピーしたばかりの API キーを取り込みます（取り込んだあとはクリップボードから消去します）。
  • フランス語以外の言語の理解：ほかの言語で書かれたリクエストを読むため、Pépouze は Google の翻訳モデル（ML Kit）を一度だけダウンロードし、その後はスマホの中で翻訳します。リクエストが送信されることはありません。

権限

初回起動時、Pépouze が求めるのは必要最低限の権限（通知とユーザー補助サービス）だけで、そのほかの権限は説明とともにご紹介します。それ以外の権限は、あなたのマクロが必要とするときにだけ、説明付きでリクエストされます。権限が必要なマクロは、その権限を許可するまで有効になりません。また、権限は Android の設定でいつでも取り消せます。

  • 通知：マクロからの通知を表示するため。
  • アラームとリマインダー：時刻指定のマクロを分単位で正確に実行するため。
  • バッテリーの制限なし：Android に Pépouze をスリープさせないため。Android の設定のアプリ情報ページで、ご自身で選択します。
  • 「おやすみモード」へのアクセス：このモードを切り替えたり、着信音をサイレントにしたりするため。
  • システム設定の変更：画面の明るさ、消灯までの時間、回転を変更するため。
  • 付近のデバイス：Bluetooth デバイスが接続されたことを知るため。
  • 電話：マクロで指定した番号に発信するため。
  • ユーザー補助サービス：次のセクションをご覧ください。
  • インターネット：オンラインバックアップ、Claude、マクロのウェブリクエストのため。通信は https のみです。

Pépouze が自ら SMS を送信することはありません。「SMS を準備」アクションはメッセージアプリを開くだけで、送信ボタンをタップするのはあなたです。

ユーザー補助サービス

このサービスは、専用の説明のあと、あなたの同意を得て有効にした場合にだけ、マクロを実行するためだけに使われます。具体的には、指定したテキストが表示されている要素をタップする、システムボタンを使う、画面をロックする、スクリーンショットを撮る、どのアプリが開いたかを知る、Pépouze が表示されていないときにアプリを開く、といった用途です。

「アプリの起動」イベントのために起動したアプリの名前を読み取り、「画面上のテキストをタップ」アクションの実行中に限り、指定したテキストを画面上で探します。これらの情報は送信も共有もされません。マクロのきっかけ（例：「アプリの起動：Waze」）だけが、スマホ内のマクロの履歴に記録されます。

Pépouze が勝手に動くことはありません。あなたが書いたルールに従うだけです。このサービスは、Android のユーザー補助設定でいつでもオフにできます。

セキュリティ

通信はすべて暗号化（HTTPS）され、API キーはスマホ内で暗号化されています。また、オンラインバックアップへのアクセスは、セキュリティルールによってあなたのアカウントだけに制限されています。

お子さま

Pépouze は 13 歳未満のお子さまを対象としていません。
