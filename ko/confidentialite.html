Pépouze는 자동화 앱입니다. 여러분이 만든 매크로(‘언제… 실행… 조건…’)는 여러분의 휴대폰에서 실행됩니다. 이 페이지에서는 앱이 어떤 데이터를 왜 사용하는지, 그리고 여러분이 무엇을 관리할 수 있는지 설명합니다.

요약

  • 매크로와 그 기록은 여러분의 휴대폰에 남습니다. 여러분이 직접 행동하지 않는 한 아무것도 전송되지 않습니다.
  • 광고는 매크로를 만들 때만: 무료 버전에서는 새 매크로를 만들 때마다 짧은 광고가 제공됩니다(또는 광고가 전혀 표시되지 않는 프리미엄 구독을 선택할 수 있습니다). 앱의 다른 곳에는 광고가 없습니다.
  • 방문자 분석은 없으며, 데이터를 판매하지 않습니다.
  • 휴대폰 밖으로 데이터를 보내는 선택 기능은 6가지이며, 여러분이 사용할 때만 데이터가 전송됩니다: 파일로 백업(Google Drive 같은 온라인 저장 위치를 선택한 경우), 계정(온라인 백업), 본인의 API 키를 사용하는 Claude, 직접 매크로에 추가한 웹 요청, 시청하기로 선택한 광고, 프리미엄 구독.

휴대폰에 저장되는 데이터

  • 매크로(그 안에 입력한 전화번호, 텍스트, 웹 주소 포함)와 실행 기록.
  • 환경설정(숨긴 도움말, 자동 백업 등)과 이용 중인 요금제(무료 또는 프리미엄).
  • Claude를 연결한 경우: API 키. 휴대폰 밖으로 절대 나가지 않는 Android 키스토어의 키로 암호화되며, 백업에서 제외됩니다.

이 데이터는 앱을 제거하면 삭제됩니다. Android 설정에서 휴대폰 백업이 켜져 있다면, 다시 설치한 뒤 복원할 수 있도록 Android가 이 데이터를 Google 계정 백업에 복사할 수도 있습니다(API 키는 제외).

파일로 백업 (선택)

‘매크로 백업’을 누르면, Pépouze는 Android 파일 선택기로 여러분이 만든 파일에 매크로를 저장합니다. 저장 위치는 Google Drive, 휴대폰, 메모리 카드 등입니다. ‘자동’이 켜져 있으면 변경할 때마다 이 파일이 업데이트됩니다. Pépouze는 이 파일에만 접근합니다. 파일은 여러분이 선택한 저장소 앱이 그 앱의 규칙에 따라 보관합니다. ‘백업 복원’은 여러분이 선택한 파일만 읽습니다.

계정과 온라인 백업 (선택)

계정을 만들면 Pépouze는 Google의 서비스인 Firebase를 사용합니다.

  • Firebase Authentication: 이메일 주소와 이름(입력한 경우), 또는 ‘Google로 계속하기’를 선택한 경우 Google 계정.
  • Cloud Firestore: 매크로 사본, 백업 날짜, 백업한 휴대폰의 기종.

이 데이터는 여러분의 계정으로만 접근할 수 있습니다. 로그아웃하거나, 내 계정 → 계정 삭제에서 계정과 백업을 삭제할 수 있습니다. Google은 자체 정책에 따라 이 데이터를 처리합니다: https://firebase.google.com/support/privacy

AI로 모듈 만들기

  • Pépouze(기본값)는 전적으로 휴대폰 안에서 작동합니다. 아무것도 전송되지 않습니다.
  • 본인의 API 키를 사용하는 Claude(선택): 여러분이 동의한 뒤, 모듈을 준비하기 위해 요청 내용과 매크로 이름이 Anthropic으로 전송됩니다. Anthropic 정책: https://www.anthropic.com/legal/privacy
  • 키 없이 Claude 또는 ChatGPT 사용: Pépouze가 요청 내용과 매크로 이름을 클립보드에 복사하고, 원하는 앱에 붙여 넣는 것은 여러분입니다. 돌아오면 Pépouze가 클립보드를 읽어 답변이나 방금 복사한 API 키를 가져옵니다(가져온 뒤에는 클립보드에서 지웁니다).
  • 프랑스어 외의 언어 이해: 다른 언어로 쓴 요청을 읽기 위해 Pépouze는 Google 번역 모델(ML Kit)을 한 번만 내려받고, 이후에는 휴대폰에서 번역해요. 요청은 절대 전송되지 않아요.

무료 버전과 광고 (선택)

무료 버전에서는 매크로를 5개까지 유지할 수 있습니다. 새 매크로는 짧은 광고를 본 뒤에 만들어지며, 프리미엄 구독이 있으면 광고 없이 만들 수 있습니다. 이미 만든 매크로는 절대 삭제되거나 잠기지 않습니다.

‘광고 보고 만들기’를 누르기 전까지는 광고와 관련된 어떤 처리도 이루어지지 않습니다. 이 버튼을 누를 때에만 Pépouze는 Google의 서비스인 Google AdMob을 사용합니다.

  • 유럽 경제 지역, 영국, 스위스에서는 처음에 동의를 요청하는 양식이 먼저 표시됩니다. 동의 내용은 나중에 내 계정 → ‘광고 개인정보 보호 선택’에서 바꿀 수 있습니다.
  • 광고를 표시하기 위해 AdMob은 휴대폰의 광고 ID, IP 주소(따라서 대략적인 위치), 기기 정보, 광고와의 상호작용을 사용할 수 있습니다. 광고는 여러분이 동의한 경우에만 맞춤화됩니다.
  • 광고 ID는 Android 설정(개인정보 보호 → 광고)에서 삭제하거나 재설정할 수 있습니다.

광고에 관한 Google 정책: https://policies.google.com/technologies/ads

프리미엄 (선택)

프리미엄은 Google Play 구독이며, Google Play에서 언제든지 해지할 수 있습니다. 활성 매크로가 무제한이고 광고가 전혀 없습니다. 결제는 전적으로 Google Play에서 이루어지며, Pépouze는 여러분의 결제 수단을 절대 볼 수 없습니다. 앱은 Google Play로부터 여러분의 Google 계정에 연결된 구독 확인만 받으며, 이를 바탕으로 여러분의 휴대폰에서 프리미엄을 활성화합니다.

권한

처음 실행할 때 Pépouze는 꼭 필요한 권한(알림과 접근성 서비스)만 요청하고, 나머지 권한은 설명과 함께 소개합니다. 그 밖의 권한은 매크로에 필요할 때만 설명과 함께 요청합니다. 권한이 필요한 매크로는 그 권한을 허용하기 전까지 켜지지 않으며, 권한은 Android 설정에서 언제든지 철회할 수 있습니다.

  • 알림: 매크로의 알림을 표시합니다.
  • 알람 및 리마인더: 시간 기반 매크로를 분 단위까지 정확하게 실행합니다.
  • 배터리 제한 없음: Android가 Pépouze를 절전 상태로 만들지 않도록 합니다. Android 설정의 앱 정보 페이지에서 직접 선택합니다.
  • ‘방해 금지’ 접근: 이 모드를 바꾸고 벨소리를 무음으로 전환합니다.
  • 시스템 설정 수정: 화면 밝기, 화면 꺼짐 시간, 화면 회전을 바꿉니다.
  • 근처 기기: 블루투스 기기가 연결되는 순간을 알아냅니다.
  • 전화: 매크로에서 지정한 번호로 전화를 겁니다.
  • 접근성 서비스: 다음 섹션을 참고하세요.
  • 인터넷: 온라인 백업, Claude, 매크로의 웹 요청, 시청하기로 선택한 광고, 구독에 사용하며, https로만 통신합니다.
  • 광고 ID: 시청하기로 선택한 광고에서만 사용됩니다(위 내용 참고).

Pépouze는 스스로 문자를 보내지 않습니다. ‘문자 준비’ 동작은 메시지 앱을 열 뿐이며, 보내기 버튼은 여러분이 직접 누릅니다.

접근성 서비스

이 서비스는 별도의 설명을 거쳐 여러분이 동의해 켠 경우에만, 오직 매크로를 실행하는 데 사용됩니다: 여러분이 지정한 텍스트가 표시된 요소 누르기, 시스템 버튼 사용, 화면 잠금, 스크린샷 찍기, 어떤 앱이 열리는지 알기, Pépouze가 화면에 없을 때 앱 열기.

‘앱 실행’ 이벤트를 위해 열리는 앱의 이름을 읽고, ‘화면의 텍스트 누르기’ 동작이 실행되는 동안에만 여러분이 지정한 텍스트를 화면에서 찾습니다. 이 정보는 전송되거나 공유되지 않습니다. 매크로를 실행시킨 계기(예: ‘앱 실행: Waze’)만 여러분의 휴대폰에 있는 매크로 기록에 남습니다.

Pépouze는 절대 스스로 행동하지 않으며, 여러분이 작성한 규칙만 따릅니다. 이 서비스는 Android 접근성 설정에서 언제든지 끌 수 있습니다.

보안

모든 연결은 암호화(HTTPS)되고, API 키는 휴대폰에서 암호화되며, 온라인 백업에 대한 접근은 보안 규칙에 따라 여러분의 계정으로만 제한됩니다.
