Makros aus der Community.

Such dir eine Idee aus, tippe auf „Code kopieren“ und dann in Pépouze auf Community → Code einfügen. Pépouze zeigt dir das Makro immer, bevor es gespeichert wird.

Ein Makro teilen

Öffne in Pépouze ein Makro und tippe auf Teilen → Code kopieren. Du kannst es auch direkt aus der App hier veröffentlichen (Teilen → In der Community veröffentlichen).

Um über die Website zu veröffentlichen, melde dich mit Google an. Dein Anzeigename ist sichtbar, deine E-Mail-Adresse nie.

Mit dem Veröffentlichen bist du einverstanden, dass alle dieses Makro sehen und kopieren können. Schreib keine Telefonnummern, Adressen oder Passwörter in ein geteiltes Makro.

Community-Regeln

  • Teile nützliche Makros, die tun, was ihr Name verspricht.
  • Keine persönlichen Daten: Nummern, Adressen, Namen von Angehörigen, Passwörter.
  • Keine Makros, die ohne Wissen der installierenden Person SMS verschicken, anrufen oder eine Website kontaktieren.
  • Ein mehrfach gemeldetes Makro wird bis zur Prüfung ausgeblendet.
